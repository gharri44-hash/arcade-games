# Arcade Lab — Netlify games

Two original browser prototypes:
- [Hold the Line](./hold-the-line/)
- [Vanguard Protocol](./vanguard-protocol/)

Both use HTML Canvas with no third-party dependencies or build command. They are simplified 2D playable prototypes, not final Unity or 3D productions.

## Deploy on Netlify
1. In Netlify select **Add new project → Import an existing project → GitHub**.
2. Authorize GitHub, select `gharri44-hash/arcade-games`.
3. Leave build command empty and set publish directory to `.` (repository root).
4. Deploy. Subsequent commits to `main` automatically deploy.

The home page and both subdirectories are standalone static pages.
